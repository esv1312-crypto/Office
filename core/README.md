# AI-OFFICE Core

Исполняемое ядро AI-ОФИСА.

Первый вертикальный срез строится вокруг устойчивого состояния задачи:

INTAKE → PLAN → EXECUTE → VERIFY → FIX/RETEST → DONE

Состояние хранится вне чата и должно переживать перезапуск процесса.

## Слои

- State — постоянное состояние проекта и задач.
- Events — журнал событий.
- Tasks — конечный автомат задач и зависимости.
- Orchestrator — управление исполнением.
- Recovery — восстановление после остановки.
- Worker — выполнение действий.
- Verification — независимая проверка.

Следующий слой подключается только после того, как предыдущий имеет проверяемый контракт.
