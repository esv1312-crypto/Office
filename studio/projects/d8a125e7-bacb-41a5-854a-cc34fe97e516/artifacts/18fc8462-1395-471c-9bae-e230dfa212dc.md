## 2. Operating model

- **One canonical register.** `register.luau` is the source of truth for status. `plan.md` explains intent. `CHANGELOG.md` records what changed and when. Status is never inferred from memory or from a chat transcript.
- **Status is derived from evidence, never asserted.** A stage is `CLOSED` only when every exit criterion has an evidence pointer that resolves to a real artifact plus a recorded observation.
- **Blockers isolate, they do not halt.** Each blocker names the independent work that continues while it is open. A blocker that stops all work is a planning failure, not a blocker.
- **Blockers gate closure, not start.** `blockedBy` on a stage means "this stage cannot close while that blocker is open". Work on the stage proceeds.

## 5. Completion rule and anti-false-completion guards

> A stage may be `CLOSED` only when every exit criterion has at least one evidence pointer that resolves to a real artifact (path plus recorded observation). Status is derived from evidence, never asserted. Allowed statuses: `OPEN`, `IN_PROGRESS`, `BLOCKED`, `CLOSED`. Partial work stays `OPEN` or `BLOCKED`.

Enforced mechanically by `validate_register.luau`:

1. A stage with an empty `exit` or `deliverables` list is rejected.
2. A stage marked `CLOSED` with an empty `evidence` list is rejected.
3. A blocker with an empty `continuingWork` list is rejected.
4. A blocker with an empty `externalDependency` is rejected.
5. Duplicate stage or blocker ids are rejected.
6. `blockedBy` and `affectedStages` must reference ids that exist.
7. `resume.stage` must exist and must not be `CLOSED`.

## 6. Resume protocol

On restart, in this order:

1. Read `ops/rollout/register.luau`. If it is missing, S0 is not closed — re-apply this artifact from §1.
2. Read `register.resume` → `{ stage, action, since }`. That is the only authoritative next action.
3. Read the last entry of `ops/rollout/CHANGELOG.md` to confirm the last verified action.
4. Do not infer status from memory, from a prior chat, or from this document. Status comes only from the register.
5. To close a stage: append the evidence pointer, append a CHANGELOG entry, then flip the status. Never flip status first.
6. Run the validator after every edit. A register that fails validation is not resumable.
