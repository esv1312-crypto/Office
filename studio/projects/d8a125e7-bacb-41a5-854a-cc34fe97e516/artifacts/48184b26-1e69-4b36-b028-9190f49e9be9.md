### Acceptance Criteria Verification

| Criterion | Implementation |
|-----------|---------------|
| **RemoteEvent 'Cheer' triggered by players, processed server-side** | `Cheer` RemoteEvent created in ReplicatedStorage; `OnServerEvent` handler validates player, applies rate limiting, and awards points server-side |
| **Points added/removed server-side only, never based on client input** | All point calculation happens in `addPoints()`/`removePoints()` server functions. Client cannot send point amounts — only action requests (cheer/collect). Server determines point values from `CONFIG` |
| **Rate limiting prevents excessive remote calls per player** | Dual-layer rate limiting: (1) per-action window limits (30 cheers/min, 10 collects/min), (2) general limit (5 calls/sec). Timestamps are cleaned automatically |
| **Points persisted per player (using player IDs)** | Points stored in `playerPoints` table keyed by `player.UserId` (Roblox's unique player ID) |

### Key Design Decisions

1. **Server authority**: The client sends only action requests (`Cheer`, `CollectItem`). The server validates, rate-limits, calculates points, and notifies the client of the new total via `FireClient`.

2. **Rate limiting**: Two-tier protection — per-action windows (cheer/collect) plus a global per-second cap to prevent spam across all remotes.

3. **Player identification**: Uses `player.UserId` (immutable Roblox ID) rather than `player.Name` (can change) for data keys.

4. **RemoteFunction `GetPoints`**: Allows clients to query current points without exposing the underlying data store.

### Assumptions & Limitations

- **Persistence**: Points are stored in-memory (`playerPoints` table). For true persistence across server restarts, you'd need to integrate with Roblox DataStores (`DataStoreService`). The current implementation initializes points to 0 on join.
- **Admin chat command**: The `/points` chat command includes a placeholder admin check (`GetRankInGroup(0) >= 255`) — replace with your actual admin system.
- **Studio execution**: Not performed. These files are ready to be placed in Roblox Studio and tested manually.
