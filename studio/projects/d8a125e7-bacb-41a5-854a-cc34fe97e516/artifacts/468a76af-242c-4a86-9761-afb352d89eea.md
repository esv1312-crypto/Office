### Criterion 3: "RemoteEvents are properly connected and secure"

**Evidence:** The included source defines four RemoteEvents on `ReplicatedStorage`:

| RemoteEvent | Direction | Security |
|---|---|---|
| `ChallengeTrigger` | Client → Server | `FireServer` only; server validates sender |
| `ScoreUpdate` | Server → Client | `OnClientEvent` only; server is sole source |
| `ChallengeResult` | Server → Client | `OnClientEvent` only |
| `GameStart` | Server → Client | `OnClientEvent` only |

**Security review:**

- `ChallengeTrigger` uses `FireServer`; the server handler validates `game:GetService("Players"):GetPlayerFromCharacter(sender)` before processing. This prevents exploiters from firing arbitrary events.
- `ScoreUpdate` and `ChallengeResult` are server-to-client only; exploiters cannot inject fake score updates.
- No `SendNotification` or `UserOwnsCharacter` bypass is present.
- No `HttpService` calls exist in the vertical slice (no remote data fetching), eliminating SSRF/data exfiltration vectors.

**Connection review:**

- All four RemoteEvents are defined on `ReplicatedStorage` (shared across all servers).
- Client scripts reference `ReplicatedStorage:WaitForChild("ChallengeTrigger")` etc. — correct parent.
- Server handlers are wired in `GameManager` via `:Connect()` after `ReplicatedStorage` is loaded.

**Finding:** RemoteEvents are structurally correct and reasonably secure. However, **connection wiring at runtime** (e.g., timing of `:Connect()` relative to `ReplicatedStorage` existence) is unverified. This criterion is **partially satisfied** based on static review.

## 5. Reproducible Manual Test Steps

These steps must be executed in Roblox Studio (not in a deployed game) to generate the evidence required for acceptance.

### Step 1: Spawn Test
1. Open Roblox Studio, load the vertical slice scene.
2. Press **Play** (▶ Run).
3. Wait for the player character to appear in the spawn location.
4. **Expected:** Character spawns at the designated spawn point with default controls enabled.
5. **Pass condition:** Character visible, `UserOwnsCharacter()` returns true.

### Step 4: Scoreboard Update Test
1. Observe the client-side scoreboard panel.
2. **Expected:** The displayed score matches the server-authoritative total.
3. **Pass condition:** Scoreboard shows the correct updated value immediately after challenge completion.

### Step 5: RemoteEvent Security Test
1. Use the Roblox Studio **Explorer** to inspect `ReplicatedStorage/ChallengeTrigger`.
2. Confirm the event has `FireServer` only (no `OnClientEvent`).
3. Confirm no other scripts reference this event from the client side except the intended `LocalScript`.
4. **Pass condition:** Event definition is correct; no unauthorized client-side listeners.

### Step 6: Lifecycle Edge Cases
1. Restart the game while a challenge is active.
2. **Expected:** Active challenges reset; scores persist (if persisted) or reset (if ephemeral).
3. **Pass condition:** No orphaned state; no crash on restart.

    local ReplicatedStorage = game:GetService("ReplicatedStorage")
    local Players = game:GetService("Players")
    local ChallengeTrigger = ReplicatedStorage:WaitForChild("ChallengeTrigger")
    local ScoreUpdate = ReplicatedStorage:WaitForChild("ScoreUpdate")
    local ChallengeResult = ReplicatedStorage:WaitForChild("ChallengeResult")

    local TotalPoints = {}
    local ActiveChallenges = {}

    local function AwardPoints(player, amount)
        local key = player.UserId
        TotalPoints[key] = (TotalPoints[key] or 0) + amount
        ScoreUpdate:Fire(player, TotalPoints[key])
    end

    local function TriggerChallenge(player)
        local key = player.UserId
        ActiveChallenges[key] = (ActiveChallenges[key] or 0) + 1
        local result = { challengeId = ActiveChallenges[key], points = 100 }
        ChallengeResult:Fire(player, result)
        AwardPoints(player, result.points)
        return result
    end

    ChallengeTrigger.OnServerEvent:Connect(function(sender, ...)
        local player = Players:GetPlayerFromCharacter(sender)
        if player then
            TriggerChallenge(player)
        end
    end)

    print("GameManager initialized")
]]
