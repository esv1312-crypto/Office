# AI-ОФИС

AI-ОФИС — универсальная агентная организация для получения, декомпозиции, выполнения, проверки и развития проектов.

Офис не ограничен фиксированным набором специалистов или одной предметной областью. Специалисты, компетенции, команды, департаменты и рабочие комнаты создаются и подбираются динамически под задачу.

## Принцип работы

INTAKE → RECON → PLAN → DELEGATE → EXECUTE → VERIFY → FIX → RETEST → EVIDENCE

## Рабочая модель

- Главный Chat/голосовой интерфейс — управление, обсуждение и координация.
- GitHub/Cloud — код, документы, задачи, сборки, тесты и рабочие артефакты.
- Chief of Staff — оркестратор проекта и агентных команд.
- Project Runner — исполняющий контур.
- Verification — независимая проверка результата.
- Evidence — обязательное подтверждение выполненной работы.
- Departments / Rooms / Competency Pools — динамические сущности, создаваемые под реальные потребности проекта.

## Продукты

Один продукт может иметь несколько клиентских интерфейсов и один общий backend.

Пример для «Погнали»:

Native Mobile + ChatGPT App → Backend → Users / Events / Social Graph / Database / API.

«Погнали» является рабочим проектом и полигоном для развития AI-ОФИСА, но архитектура ОФИСА не должна зависеть от его предметной области.
