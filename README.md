# AI-ОФИС

AI-ОФИС — универсальная агентная организация, которая принимает задачи, планирует, распределяет работу между специалистами, создаёт продукты и проверяет результаты.

**Текущая стратегическая задача: научить AI-ОФИС самостоятельно исследовать, достраивать и улучшать собственный код.** Пользователь ставит задачу директору; директор формирует план, назначает специалистов, workers работают с GitHub в изолированной ветке, независимый QA проверяет изменения, а production-изменения проходят отдельное согласование.

Офис не ограничен Roblox или разработкой ПО. Он должен динамически создавать роли, компетенции, команды, департаменты и рабочие комнаты под любую область.

## Принцип работы

INTAKE → RECON → PLAN → DELEGATE → EXECUTE → VERIFY → FIX → RETEST → EVIDENCE

## Рабочая модель

- Главный Chat/голосовой интерфейс — управление, обсуждение и координация.
- GitHub/Cloud — код, документы, задачи, сборки, тесты и рабочие артефакты.
- Director / Chief of Staff — анализ запроса, планирование и делегирование.
- Specialists / Workers — выполнение задач через разрешённые инструменты и модели.
- Independent QA — отдельная проверка реального результата.
- Evidence — проверяемые SHA, read-back, тесты и QA findings.
- Departments / Rooms / Competency Pools — динамические сущности под реальные потребности.
